\## 🚀 Project Overview



Smart File Organizer is a Python-based desktop application designed to simplify file management by automatically organizing files into categorized folders.



It helps users manage cluttered directories, identify duplicate files using file hashing, and generate reports for better file management and tracking.



The project combines Python programming, file handling, GUI development, duplicate detection, and automated reporting into one application.



\## ✨ Features



\- \*\*Automatic File Organization:\*\* Organizes files into categorized folders based on file types.

\- \*\*Duplicate File Detection:\*\* Identifies duplicate files using file hashing.

\- \*\*Graphical User Interface:\*\* Provides a desktop interface for interacting with the application.

\- \*\*CSV Reports:\*\* Generates file organization reports in CSV format.

\- \*\*Duplicate Reports:\*\* Creates reports containing duplicate file information.

\- \*\*File Size Reports:\*\* Generates reports showing file size information.

\- \*\*Activity Logging:\*\* Maintains logs of application activities.

\- \*\*Unit Testing:\*\* Includes automated tests to verify core functionality.

\## ⚙️ Installation \& Setup



\### 1. Clone the Repository



```bash

git clone https://github.com/DevKumarBhatt/smart-file-organizer.git

```



\### 2. Navigate to Project Directory



```bash

cd smart-file-organizer

```



\### 3. Create a Virtual Environment



```bash

python -m venv venv

```



\### 4. Activate Virtual Environment



\*\*Windows:\*\*



```powershell

.\\venv\\Scripts\\Activate

```



\### 5. Run the Application



```bash

python src/gui.py

```



\## 🧪 Run Tests



Execute the following command to run the unit tests:



```bash

python -m pytest -v

```
